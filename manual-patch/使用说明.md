# Hank: Straightjacket 手动汉化教程（免安装、免脚本、免管理员权限）

本方案**不运行任何来自本仓库的程序**：所有会执行的文件（BepInEx、XUnity.AutoTranslator、UABEA）都从它们的官方 GitHub 发布页下载，你只需要做**复制文件**和**几步图形界面操作**。不需要管理员权限，不需要关闭杀毒软件。

---

## 最终效果

界面、剧情对白、玩家选项、动态字幕全部中文；保留打字机文字动效与台词重点词标红。

## 前置要求

- Windows 10/11，Steam 版《Hank: Straightjacket》（免费）
- 系统已安装 **Noto Sans SC** 字体（Windows 11 自带；Windows 10 可从 [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+SC) 免费下载安装）
- 操作前请**完全关闭游戏**

---

## 第 1 步：安装汉化框架（官方开源组件，负责中文字体渲染）

1. 下载 **BepInEx 5.4.23 x64**：
   <https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.2> → `BepInEx_win_x64_5.4.23.2.zip`
2. 下载 **XUnity.AutoTranslator 5.6.1**：
   <https://github.com/bbepis/XUnity.AutoTranslator/releases/tag/v5.6.1> → `XUnity.AutoTranslator-BepInEx-5.6.1.zip`
3. 把**两个压缩包的内容**先后解压到游戏根目录（就是 `Hank_Straightjacket.exe` 所在目录），选择"替换目标中的文件"。
   解压完成后游戏目录应多出：`BepInEx\` 文件夹、`winhttp.dll`、`doorstop_config.ini` 等文件。

## 第 2 步：复制本仓库的汉化文件

把本仓库 `manual-patch\` 文件夹里的内容，按原样复制进游戏根目录（合并文件夹）：

```
manual-patch\BepInEx\config\AutoTranslatorConfig.ini              → 游戏\BepInEx\config\
manual-patch\BepInEx\Translation\zh\Text\_AutoGeneratedTranslations.txt → 游戏\BepInEx\Translation\zh\Text\
```

到这一步为止，启动游戏：**菜单和大部分对话已经是中文**。如果你只想做到这里，可以停手了（少数动态加载的字幕可能仍是英文）。要 100% 全文本覆盖，继续第 3 步。

## 第 3 步（可选但推荐）：替换游戏文本资产，实现全文本中文

用开源的 UABEA 图形工具，把你自己的游戏文本资产改写为中文（本仓库提供现成的中文文本文件）：

1. 下载 **UABEA**（开源）：<https://github.com/nesrak1/UABEA/releases> → `UABEA-v*.zip`
2. 进入游戏目录 `Hank_Straightjacket_Data\`，**先复制一份 `resources.assets` 改名为 `resources.assets.bak` 备份**
3. 打开 UABEA → `File - Open` 选择 `resources.assets` → 在列表中找到名为 **`en`** 的行（Type 为 TextAsset）→ 点 `Plugins - Edit Text`（或双击进入文本编辑）→ 全选删除原文，把本仓库 `manual-patch\cn_text\en.txt` 的全部内容粘贴进去 → 确定 → `File - Save`
4. 同样方法处理名为 **`seq_en`** 的行，粘贴 `manual-patch\cn_text\seq_en.txt` 的内容并保存
5. 启动游戏即全部中文

> UABEA 具体按钮名称随版本略有差异，核心操作就一句话：**用 UABEA 的文本编辑功能，把 `en` 和 `seq_en` 两个 TextAsset 的内容分别替换为 `cn_text\en.txt` 和 `cn_text\seq_en.txt` 的内容，然后保存。**

---

## 恢复英文原版

- 只做了第 1、2 步：删除游戏目录下的 `BepInEx\`、`winhttp.dll`、`doorstop_config.ini` 即可
- 做了第 3 步：把备份的 `resources.assets.bak` 改回 `resources.assets`（删掉改完的文件）
- 或者：Steam 库中右键游戏 → 属性 → 已安装文件 → **验证文件完整性**，自动还原

## 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 中文显示为方块 □□□ | 系统缺少 Noto Sans SC 字体，安装后重启游戏 |
| 文本仍是英文 | 第 2 步的文件没复制对位置；确认 `_AutoGeneratedTranslations.txt` 在 `BepInEx\Translation\zh\Text\` 下 |
| Steam 验证后变回英文 | 验证会还原文本资产，重做第 3 步即可 |
| 杀毒软件提示 winhttp.dll | 该文件来自 BepInEx 官方发布包（开源、业界通用），属于对注入式框架的通用提醒，可自行校验官方包哈希 |
